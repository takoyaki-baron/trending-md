# エージェント体験という配布チャネル

初回アーカイブ 2026-09-04（テーゼ 16）。観察の核心：「エージェントはどのツールを選ぶか？」は測定可能で、
金額に関わる問いになった。エージェントは今や開発者ツールの配布チャネルであり——同じ力が、開発者が
プラットフォームをどこで学ぶのかさえ作り変えている。2026 年 9 月 3 日に同日着地した 2 つのデータ点が、
このレンズを逸話から測定へ変えた。

## 測定——Armature の 16,893 実行ツール選択研究（9月3日）

Armature は 75 の合成リポジトリ（架空企業名・実在ロックファイル）上で 16,893 セッション（5,292 有効）を
10 言語・18 業種で実行した。Gemini 3.7 Flash インスタンスがユーザーを演じ、別インスタンスが審判を務め、
エージェントが実際に実装したサードパーティサービスを測定した。

- Claude Code・Codex・Cursor が同じツールに収束するのはセルの **42% のみ**。
- ランキングより情報取得の違いが大きい：Cursor はセッションの約 2/3 でウェブ検索、Codex は 94%、
  Claude Code は約 30%——先験で動く。
- 同一の依頼でもメール SDK の勝者は言語で変わる：TypeScript は Resend、Python は SendGrid、Go は
  Postmark。
- Stripe は 9/10 で勝つ。PayPal は 139 回引用され一度も選ばれず、最多言及のデータベース Supabase は
  Neon に負けた。

**警告の自己開示が異例に完全で、数字と一緒に引用すべき：** Armature は開発者ツール向け成長サービスを
販売する利害当事者であり、実行の約 31% のみ公開、シミュレートユーザーも審判も LLM である。方向的な
参考であり、福音ではない。詳細は [[agent-stack]] も参照。

## エッセイ——Nolan Lawson「フロントエンド Web 開発に今まさに衝突しつつある小行星」（8月23日）

Lawson（長年ブラウザ性能エンジニアリングに携わった）が主張するのは、AI の最初の構造的被害がフロント
エンドの*知識共有*層に落ちるという仮説だ：Axel Rauschmayer、Salma Alam-Naylor、Josh Comeau が教育活動
を終了・縮小し、Kent C. Dodds と Addy Osmani は AI コンテンツへ方向転換した。彼のメカニズム：

- フロントエンドは最もリスクの低い代替ターゲット——React コンポーネントは無監督で出荷でき、データベース
  マイグレーションはそうはいかない。
- 「エージェント体験」が今や「開発者体験」を上回る：Cursor は Solid→React を、Viget は Lit→React を
  移行した——「エージェントが React を知っているから」。
- Lawson 自身、Chrome trace の性能問題を今なら Claude Code に丸投げすると認める（Sonnet は彼の得意の
  ニッチな質問に正答した）。

彼自身の警告：標準に関する予測は推測であり、コンサルティング帰込みの賭けが「一番不安定」で、AI バブル
は弾け得る。このフィードにとっての再帰的含意：プラットフォームを説明する人たちが説明をやめれば、今日の
エージェントの*未来の*学習データには崖がある——教育層はモデルの上流にある。

## なぜ重要か

- ツールベンダーにとって「エージェント体験」（エージェントはあなたの製品を知っているか？ドキュメントは
  教えられるか？）は数字の付いた配布チャネル——コンパイラがループに入った SEO/回答エンジン問題
  （[[answer-engine-seo]]）。
- エージェントビルダーにとって、ツール選択の乖離（42% の一致）は、同一プロンプトがエージェントと言語ごと
  に異なるスタックを生むことを意味する——再現性に「どのハーネスか」が含まれた。
- ウェブの学習可能性にとって、代替の順序は通例の「ジュニア開発者から」という物語と逆である：教える層が
  最初に消える。

## 開いた問い

- **独立**（非ベンダー）のエージェント露出測定は存在しうるか、それともスキル評価がかつて著者自己評価に
  独占されたように、利害当事者が数字を独占するのか？（→ [[agent-plugins]]）
- 「どのメール SDK か」の知見はよりハイリスクな選定（クラウド、認証、決済コンプライアンス）に一般化する
  のか、それともエージェントはそこで人間に譲るのか？
- 教育コンテンツの縮小が続けば、エージェントの知識はベンダードキュメントの更新よりも速く陳腐化しない
  か——その減衰を誰が測るのか？
