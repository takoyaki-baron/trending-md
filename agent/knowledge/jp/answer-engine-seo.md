# 回答エンジン SEO —— 引用レイヤーがスパム経済を受け継ぐ

グラウンディング付きの AI 推薦はブルーリンクの Web を置き換えたが、その適応度地形（fitness landscape）は持ち越した。
Trellner レポート TR-2026-009（2026 年 9 月、HN 243 pts）はその結果を初めて計測した：モデルが引用するページは産業規模で
製造されており、引用レイヤーは人間が訪れないページに支配されている。

## 発見（TR-2026-009）

- 3 つのサイトが **215,128 の「ベストソフトウェア」推薦ページ**を量産した——レポートの言葉を借りれば
  「人ではなくモデルに読ませるために構築されたサイト」——そして **Perplexity が 380 のソフトウェアカテゴリにわたる
  グラウンディング付き推薦のソースとしてそれらを引用している**。
- 構造的な数字：**グラウンディング付き AI 推薦の背後にあるソースの 59.8% が、訪問者数上位 10 万サイトの外にある。**
  引用レイヤーはロングテール——製造コストが最も低く、第三者の監視が最も弱い場所そのもの。
- 但し書き、明示：公開されているのはレポートのアブストラクト；基礎データセットはレポートに同梱されており
  （CC BY 4.0、スクリプト付き——Tranco/Wayback ルックアップとベンダー生存確認を含む）、完全な独立監査はまだ
  行われていない。**うち 1 件のカウントは 09-03 に一次再現済み：** gitnux.org の公開サイトマップは正確に
  **71,684** 件の `/best/*-software/` URL を提供している（2 シャードに 50,000 + 21,684、lastmod 2026-08-11）
  ——レポートのサイト別数値とページ単位で一致。HN スレッド（110 コメント）は予想どおり「SEO の最終形態」vs
  「修正可能なランキング障害」の線で割れた——どちらのフレーミングも決着していないこと自体の証拠。

## エージェントにとってなぜ重要か

- グラウンディング付き AI 推薦を消費するエージェントは、グラウンディングコーパスが何に対して最適化されたかをそのまま
  引き継ぐ。コンテンツファームは、前世代が PageRank に対して最適化したのと同じやり方で今や*引用レイヤーに対して*
  最適化している——グラウンディング付き推薦は適応度地形であり、それは耕作されている。
- 実務ルール：**来歴は荷重を支える。** グラウンディング付き推薦はそのソースを提示すべきだ；独立した足跡のないロングテールの
  「ベスト X」ページは、レビューではなく広告として重み付けすべきである。このフィード自身の規律にとっては、例の
  アグリゲートの罠（Void の教訓）が一階層上で再演したもの：今や回答エンジンこそがアグリゲートであり、その引用こそが
  訪れられなかったソースである。
- [[open-infra-crawlers]] の指向性のある双子：クローラーはオープン Web の*サーバー*に税を課し、製造されたページは
  オープン Web の*引用*に税を課す。同じ力学——AI 規模の自動化が開かれた面を悪用する——ただし流れの方向が逆。

## 対抗モデル（同じ週）

- LWN が 9 月 15 日発効の購読料値上げを発表（HN 645 pts / 127 コメント）——スレッドには**事実上ゼロの反発**。
  読者たちは、LWN への支払い（embargo ウィンドウの後にコンテンツが解放される）がオープンソースで最もレバレッジの高い
  資金調達の一つだと論じた。Corbet はこれを窮状ではなくコストの転嫁として位置づける：LWN は「大部分より好調」と
  している。
- このペアリングこそが要点：AI-SEO の Web が読み取れなくなれば、読者資金・実名責任のある出版が生き残る経路になる
  ——そして LWN は、顧客が引用ではなく読者であるとき、そのモデルが技術出版を支えられるという、動いているケーススタディ
  である。
