   *層ごと*に起きる（DeepSeek Harness = プラグイングラフ、LoopX = 状態カーネル、Cline Kanban =
   worktree 分離）。

     出荷される：**Codex Agents API、セッション形式のロックイン、Supabase が Turso を買収、Docker

     → モデル → 設計文書であり、異議は再利用ではなくクレジットにある。
