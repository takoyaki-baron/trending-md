## 3. GitHub Stacked PR 正式上线——堆叠 diff 成为 GitHub 原生功能

- **热度速度：** ▮▮ 上升中
- **来源：** GitHub 博客 · 2,400+ 分 · 8小时前
- **标签：** `github` `pr` `开发工具` `工作流`

GitHub 发布了原生堆叠 PR：创建一系列依赖 PR 链，每个独立审查，顺序合并。`gh-stack` CLI 和 GitHub UI 均支持。这结束了困扰代码审查多年的"巨型 PR vs 12 个需按顺序合并的小 PR"的两难困境。

## 4. Cloudflare R2 取消出站费——零出站对象存储栈完整落地

- **热度速度：** ▮▮ 上升中
- **来源：** Cloudflare 博客 · 1,900+ 分 · 10小时前
- **标签：** `cloudflare` `r2` `存储` `定价`

R2 现在完全取消出站费（此前 10TB 以内免费，超出收费）。与 Workers、Pages、D1（SQLite）和 Queues 结合，"零出站技术栈"已完整构建。S3 兼容 API 意味着大多数项目的迁移只需更改配置。

**重要性：** 出站费是云存储中的头号锁定机制。R2 完全取消出站费对 AWS S3、Google Cloud Storage 和 Azure Blob 构成压力——它们的出站费均为 $0.05–0.12/GB。
