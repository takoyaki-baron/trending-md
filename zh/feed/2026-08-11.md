## 12. Needle2 —— 14MB 智能体大模型，为手机、可穿戴设备和树莓派带来工具调用能力

Ladybird（64k+ 星）是自 2013 年 Google Blink fork 以来首个真正的全新浏览器引擎。从零构建——非 Chromium、非 WebKit、非 Gecko——拥有自己的 LibWeb 渲染器、LibJS JavaScript 引擎和 LibWasm。由 Andreas Kling（前 Apple WebKit 工程师）和 Chris Wanstrath（GitHub 联合创始人）创立，由 501(c)(3) 非营利组织管理，获得 Cloudflare、Shopify、Proton、JetBrains 和 37signals 支持。Linux/macOS Alpha 版本计划 2026 年夏季发布，Beta 版 2027 年，稳定版 2028 年。多进程沙箱隔离，97.8% test262 通过率，已可加载 Gmail 和 Figma。安全关键组件正迁移至 Rust。

## 17. CVE-2026-19516（CVSS 9.1）——mcp-grafana 严重 SSRF 漏洞通过 MCP 工具暴露内部网络

- **热度速度：** ▮ 稳定
- **来源：** CVE/NVD · 850 分 · 18小时前
- **标签：** `安全` `cve` `mcp` `grafana` `ssrf`

CVE-2026-19516（CVSS 9.1）影响 mcp-grafana（Grafana 的 MCP 服务器），版本 0.0.0–1.0.0。调用者提供的 `X-Grafana-URL` 头部控制了出站请求的目的地，而 `grafana_api_request` 工具允许调用者选择 HTTP 方法、路径和请求体。由于目的地未限制为已配置的 Grafana 实例，攻击者可以瞄准内部服务、环回接口和云元数据端点（169.254.169.254）——并读取响应。此前针对 CVE-2026-15583 的修复仅阻止了 token 泄露，但未限制目的地。

**重要性：** MCP 服务器正在成为智能体生态系统中的关键基础设施。此 CVE 是一个警告：每个进行出站请求的 MCP 工具都是潜在的 SSRF 载体。随着 MCP 采用的加速，MCP 专属 CVE 将成为常规类别。

> 应急措施：在反向代理层剥离 `X-Grafana-URL` 头部；对 mcp-grafana 主机应用出站过滤，阻止内部/RFC1918 地址范围。
