## 20. Walgit：一个二进制文件 + 对象存储 = Git 服务器

- **Velocity:** ▮ steady
- **Source:** Hacker News · 59 分 · 7 评论 · 约 41 小时前（提交于 9 月 26 日 03:09 UTC）
- **Tags:** `git` `s3` `self-hosted` `storage`

Walgit（`rgodha24/walgithub`，MIT）托管 Git 仓库时不需要数据库、不需要
leader 节点、几乎没有本地状态：一个指向任意 S3/GCS 存储桶的二进制文件，
即可提供 smart HTTP v0/v2 的 fetch 与 push、以静态文件实现的 `bundle-uri`
克隆、Git LFS、Web UI、带 SDK 的 JSON API、按仓库的推送策略和 webhook。卖
点一句话："运行 walgit 的每台机器都是可丢弃的缓存；存储桶才是仓库"——仓
库可以比机器本身还大。注意：项目才几天大、单一作者、59★——一个有前景的
设计演示，不是生产级基础设施；尚无独立部署或审计。

**Why it matters:** 它把自托管 forge 的问题压缩成"存储桶 + 二进制"——与
JGit-on-S3 类设计同一架构方向，对厌倦了为托管 git 而维护数据库的人很有吸
引力。
